# Proceso de Alta de Cliente (operativo)

Ultima actualizacion: 2026-05-14

Objetivo: dar de alta un cliente en menos de 24h con pasos repetibles.

## Flujo de alta

1. Recepcion de solicitud
- Canal: email a christiancosacoronado@hotmail.com
- Datos minimos solicitados:
  - Nombre del club o equipo
  - Persona de contacto
  - Email de contacto
  - Numero de equipos a gestionar
  - Plan elegido

2. Confirmacion comercial
- Enviar resumen de plan, precio y condiciones.
- Confirmar aceptacion por email.

3. Provision tecnica
- Crear usuario admin del cliente.
- Confirmar acceso inicial.
- Compartir URL: https://volleyballmanager.up.railway.app

4. Onboarding inicial
- Enviar guia rapida de uso (primeros pasos).
- Recomendar carga inicial de jugadoras y primera jornada.

5. Cierre de alta
- Registrar cliente en un listado interno de control.
- Registrar fecha de activacion y plan en este repositorio o sistema interno.

## Flujo de baja

1. Recepcion de solicitud de baja.
2. Ofrecer exportacion de datos al cliente.
3. Ejecutar baja de acceso al cierre del periodo pagado.
4. Si aplica, borrado de cuenta y datos asociados.
5. Registrar fecha de baja para trazabilidad.
